# 讀書筆記本系統 PRD (Product Requirements Document)

## 1. 專案概述
### 背景與動機
許多喜歡網路閱讀的使用者缺乏一個簡單、專注的工具來記錄和管理他們閱讀過的書籍與心得。此專案旨在打造一個「讀書筆記本系統」，提供一個方便使用的應用程式，讓閱讀愛好者能夠輕鬆記錄、整理及回顧他們的閱讀軌跡。

### 目標用戶
- 喜歡閱讀者
- 有記錄讀書心得與書單管理需求的使用者

### 核心價值主張
提供直覺且便捷的書籍記錄與收藏功能，幫助使用者系統化地累積閱讀筆記，並能快速搜尋過去的閱讀紀錄與評價。

## 2. 功能需求
以下為系統的主要功能清單與對應的使用者故事（User Stories）：

1. **記錄書名**
   - 作為 **閱讀愛好者**，我希望 **能夠輸入並儲存我正在閱讀或已閱讀的書名**，以便 **追蹤我的閱讀書單**。

2. **撰寫心得**
   - 作為 **閱讀愛好者**，我希望 **能夠為每一本書撰寫與儲存讀後心得**，以便 **日後回顧我的想法與收穫**。

3. **書籍評分**
   - 作為 **閱讀愛好者**，我希望 **能夠對書籍進行評分（例如 1~5 星）**，以便 **快速辨識我最推薦或喜愛的書籍**。

4. **搜尋功能**
   - 作為 **閱讀愛好者**，我希望 **能夠透過書名或心得關鍵字搜尋過去的紀錄**，以便 **在需要時快速找到特定的書籍或筆記**。

5. **收藏書本**
   - 作為 **閱讀愛好者**，我希望 **能夠將特定書籍標記為「收藏」**，以便 **建立我的最愛書單並能快速存取**。

## 3. 非功能需求
### 技術限制
- 後端框架：Flask
- 模板引擎：Jinja2
- 資料庫：SQLite

### 效能與安全考量
- **效能**：系統操作（如新增筆記、搜尋）需在合理時間內（如 1 秒內）回應，確保流暢的使用者體驗。資料庫查詢需進行適當優化，以應對日漸增長的閱讀紀錄。
- **安全**：
  - 確保防範常見的 Web 攻擊，如防止 SQL Injection 與 XSS 攻擊，確保使用者輸入的心得與書名資料安全。
  - 若系統包含多使用者機制，需妥善處理密碼加密（雜湊處理）與工作階段（Session）管理。

## 4. MVP 範圍 (Minimum Viable Product)
### Must Have (必須擁有)
- 新增書籍紀錄（包含書名、心得、評分）
- 書籍列表：顯示所有已記錄的書籍清單
- 編輯與刪除既有的書籍紀錄

### Should Have (應該擁有)
- 透過書名或心得內容進行關鍵字搜尋
- 將書籍加入/移除收藏清單，並可篩選檢視已收藏的書籍

### Nice to Have (最好擁有)
- 標籤（Tag）與分類系統，方便整理書籍
- 閱讀狀態追蹤（如：想讀、閱讀中、已讀）
- 簡單的閱讀數據統計（如：年度閱讀數量、平均評分）
